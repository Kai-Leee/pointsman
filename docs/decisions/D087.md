# D087 — Codex 판단과 Jev 판단 실제 개발 재측정

사용자는 Claude 대신 Codex로도 지금 측정을 시작하도록 요청했다. 같은 Codex 작업자를 두고 판단 주체만 바꾸는 순차 한 쌍을 새 디렉토리에서 실행한다. [역할과 범위](../agents/D087_CODEX_COMPARISON.md), [조건 정본](../../benchmark-runs/d087-codex-20261016-01/protocol.json), [실제 실행 경로](../../benchmark-runs/d087-codex-20261016-01/pair/).

이번은 기존 Codex 경로(D083+부분 실행 수리/공개 담당 근거)이며 D085의 복수담당·평평한답재질문·생성오류직접수리를 포함하지 않는다. 이 범위와 지원 모델5.6 선택을 실제 호출 전에 사용자에게 알렸다. 기존 D085 Claude 시도의 직접 대체 조건으로 보고하지 않는다. 실행전 역할·가설·조건·장부·후속트리거는 protocol과 역할 문서에 남겼고, 이 구조화 기록은 실행 시작 뒤 추가했다.

가설은 반복 관계/담당 판단을 Jev에 맡겨 같은 공개·독립 품질을 만족하며 전체 시간·비용을 줄이는 것이다. 현재 실행 중이며 절감은 미측정이다.
