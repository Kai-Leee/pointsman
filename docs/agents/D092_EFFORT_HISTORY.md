# D092 — 모델·노력도와 과거 공개 성과 기반 선택

2026-10-17 사용자 지시: high 고정을 제거하고 제공되는 노력도를 모델과 함께 선택지에 포함한다. 실측 성공률을 선택 입력에 반영해 재호출을 줄인다. 과거 실험 실패와 해결 경로를 최신 D091 실패와 함께 대조한다.

작업 위치는 D091 worktree의 현재 브랜치다. 과거 결과와 v1 프로필 계약은 보존한다. D092 v2 모듈·v9 gateway·새 manifest를 추가한다. 성공률은 공개 검사와 현재 소스/작업자 영수증이 연결된 관측만 사용한다. 숨김 검사 상세나 독립 채점 결과는 라우팅 학습 입력에 사용하지 않는다. 샘플 부재는 unknown이고 작은 표본을 보장으로 해석하지 않는다. 원래 공유 장부와 전송 사전 검사·응답 검증·실행 기록을 유지한다. 근거 없는 자동 재시도와 과거 실행 재개를 하지 않는다.

## 역할과 파일 소유

- root: runner/bin/environment/gateway/manifest/핀 통합, 실제 제공 노력도 discovery, 공통 검증과 기록. 기존 D091 실행 당시 439파일 스냅샷/원시 결과는 수정하지 않는다.
- d086_runner_pair: 새 `codex-worker-profiles-v2.mjs`, `codex-worker-profiles.v2.json`, 해당 집중 테스트만 소유. 모델×노력도 교집합 후보, 고정 영어 질문, 실측 공개 성과 입력·선택/실행 binding·정본 검증. v1 불변. root와 history 담당의 API를 합의한다.
- capability_audit: 새 과거 공개 성과 집계 모듈·오프라인 CLI·테스트·새 private 결과. 공개 검사와 worker receipt/선택 모델/effort/파일 revision을 연결해 success/failure/unknown 분모, no-op/재수리/토큰/시간을 집계한다. 숨김 검사와 독립 결과는 모델 입력에서 제외. exact task/phase와 전체 집계를 구분하고 같은 입력/수정 근거에 대한 실패 재호출을 식별한다. 생산 모델 라우터/runner/gateway 수정 금지.
- skill_audit: 읽기 전용 과거 D081/D083/D087–D091 공개 실패·수리 흐름과 이번 사례 대조. 원인/조치/실제 해결/재발/환경 차이 구분, 파일 경로와 명령/분모를 남긴다. 새 D092 실패 분석 문서/private audit만 작성. 과거 문서·실험·생산 코드 수정/모델/계정/Docker/장부 호출/hidden 상세 접근 금지.

모델·계정·Docker·장부 작업은 root만 한다. 독립적인 위 역할은 병렬로 수행한다. 새 정책은 v1과 별도이며 이전 핀을 최신 소스에 맞추기 위해 조용히 변경하지 않는다. 구현 완료·로컬 검증·실제 모델 호출·전체 개발 완료를 구분한다. 비용/시간 개선은 새 완료 측정 전 미측정이다.
